# Kerala Wedding Card — exact HTML conversion

This project is the Vite/React version of the supplied wedding-card HTML.

The invitation content, colors, typography, animation timings, countdown date, map URL, music behavior, and layout are kept from the supplied HTML.

## Required assets

Place these two files in `public/assets/`:

- `couple.jpg`
- `sita-kalyana-vaibhogame.mp3`

They were referenced by the supplied HTML but were not included in the uploaded source.

## Run

```powershell
npm install
npm run dev
```

Then open http://localhost:5173/
